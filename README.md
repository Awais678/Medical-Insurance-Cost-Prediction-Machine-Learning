# Medical-Insurance-Cost-Prediction-Machine-Learning

## Overview
This project predicts medical insurance charges using Machine Learning regression techniques. The dataset includes demographic and health-related features such as age, BMI, smoking status, number of children, sex, and region.

The goal is to build a predictive model that estimates insurance cost and analyze which factors have the strongest impact on medical charges.

---

## Dataset
Dataset used: Medical Cost Personal Dataset (Kaggle)

Link: https://www.kaggle.com/datasets/mirichoi0218/insurance

### Features
- age: Age of the person  
- sex: Gender  
- bmi: Body Mass Index  
- children: Number of dependents  
- smoker: Smoking status  
- region: Residential area  
- charges: Medical insurance cost (Target Variable)
